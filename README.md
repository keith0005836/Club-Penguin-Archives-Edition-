# 📁 Club Penguin SWF Archive

🚧 **This project is under development!**

The goal of this repository is to collect and organize all the `.SWF` files used in the old Club Penguin game.

These files will be organized into folders for easy access and historical preservation.

## 📌 What are SWF files?

SWF files are used to store animations, minigames, interfaces, and other elements of Club Penguin.

## 📂 Project Structure
/club-penguin-swf
├── games/
├── items/
├── rooms/
├── characters/
└── outros/
