# 🐧 Club Penguin SWF Archive

> Archiving nostalgia, one `.SWF` file at a time.

---

🎯 **Status:** `🚧 In Development`
📁 **Project Type:** Digital Preservation / Archiving
🕹️ **Contents:** Static `.SWF` files from Club Penguin
❌ **Important:** **Does not include games or interactive animations**

---

## 📖 About the project

The **Club Penguin SWF Archive** is a repository dedicated to the **visual preservation of the Club Penguin universe**, bringing together `.SWF` files used in the old Disney online game.

Our focus is on **organizing and documenting static visual elements**, such as:

- Room layouts
- Characters and mascots
- Collectibles
- Game interfaces
- Icons, buttons, and other visual resources

This project is lovingly crafted to keep the memory of Club Penguin alive and provide a clean, safe, and accessible visual reference.

---

## 📁 Repository structure
/club-penguin-swf
├── rooms/ → Rooms and maps
├── items/ → Clothes, accessories, pins, puffles
├── characters/ → Pets, NPCs, agents
├── ui/ → Buttons, menus, interfaces
├── stamps/ → Game stamps
└── others/ → Files that do not fit into the categories above
